# Agent Collaboration Reflection

The sequential hand-offs make each agent's contribution inspectable: the Market Researcher produces an evidence ledger, the Financial Analyst receives that work and returns a calculation sheet, and the Marketing Writer must use both as context. The Sustainability Officer then checks environmental statements separately, before the Skeptical Reviewer sees every prior output and produces the final brief. This division makes unsupported claims easier to locate than asking one general-purpose agent to research, calculate, and persuade at once.

The most important quality improvement came from inspecting the Kaggle source rather than trusting its title. Although the file contains 1,000 student-shaped records and a food-spending column, the publisher says the data is entirely fictional. Treating those values as observed behavior would create false evidence; the team therefore preserves the file for technical practice but excludes it from the brief. The financial analyst also separates a transparent planning scenario from a forecast, while the reviewer is explicitly asked to recalculate the result and remove claims without sources.

This process does not make generated research automatically reliable. Search can fail, national evidence may not represent this campus, and cost assumptions are not vendor quotes. The brief consequently flags demand as unknown and recommends collecting local sales, price, and waste data before permanent investment. The sustainability review helps catch broad green claims, but cannot substitute for measuring product-level impacts. A live run still requires an LLM API key and current source checks; the committed brief is a cautious example, not a substitute for local validation.
