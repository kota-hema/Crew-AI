# Kaggle dataset

- Dataset: [Student spending habits dataset](https://www.kaggle.com/datasets/sumanthnimmagadda/student-spending-dataset)
- Creator: Sumanth Nimmagadda
- License shown by Kaggle: Apache 2.0
- Downloaded: 2026-10-16 from Kaggle's public dataset download endpoint
- Included files: `student_spending.csv` and the original downloaded ZIP

The Kaggle dataset description explicitly says the 1,000 records are entirely fictional. Its `food` field is not a measure of cafe purchases, and the description does not specify the spending period. Its values are not evidence about actual students. The app's Dataset Explorer uses the CSV for synthetic-sample exploration only; the brief's factual claims must use independent cited sources.
